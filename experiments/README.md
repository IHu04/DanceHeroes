# Hackathon experiments

These files preserve distinct earlier experiments from the original repository. They are excluded from the runnable app and source ZIP export.

- `legacy-ui/`: alternate motion-capture, model, and camera prototypes.
- `legacy-backend/`: earlier scoring APIs and browser scripts that were mixed into the backend directory.
- `fbx-to-vrm/`: standalone retargeting experiment.
- `test.fbx` and `preview.glb`: additional original model experiments.

Use `frontend/` and `backend/` to run the restored game. These experiments may still contain old asset paths and dependencies.
